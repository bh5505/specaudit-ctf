# Pinned k8scout report import

This is a stdlib-only, offline parser for a selected k8scout offensive-mode JSON `Report`, source revision [`031c8bc4fc6579aab9d1df2e781697968028a427`](https://github.com/k8scout/k8scout/tree/031c8bc4fc6579aab9d1df2e781697968028a427). Read-only primary inspection on 2026-10-03 checked `pkg/output/types.go` (`Report`, `MetaBlock`), `pkg/output/json.go` (`WriteFile` encoder), `pkg/graph/types.go` (`Graph`, `Node`, `Edge`), `pkg/graph/inference_types.go` (`RiskFinding`) and `pkg/graph/traverse.go` (`PathStep`). The repository README documents `--out` JSON. Its checked-in `web/sample.json` has older `k8s-enum` metadata and lacks required fields, so it was **not** treated as a valid current export. The teaching report is original and synthetic; upstream implementation or sample code was not copied. Upstream code at that revision is MIT; this package does not bundle it.

The capture sidecar is our own schema, `specaudit.k8scout-capture.v1`, because k8scout's report does not include the immutable raw hash, capture custody, authorized subject/scope or completeness declaration needed for this exercise. The importer checks the pinned source revision, raw SHA-256 and identity match. It rejects reviewer-mode reports, recon/no-graph reports, unrecognized top-level fields, `ai_narrative`, duplicates, dangling graph/path references, malformed types and oversize input. JSON parse and normalization never execute target-controlled text. A graph edge without `inferred=true` is still classified **tool-reported**, not independently observed. `allowed-check-candidate` never means effective access.

Run the [learner case](fixture/README.md) with `python -m k8s_path_evidence --report ... --capture ...`. This offline parser and runnable synthetic exercise are implemented; no live scanner integration or collector-produced capture has been validated. The answer key lives separately at `challenges/lab-k8s-01-rbac-path/instructor/KEY.md`; distribute only the fixture directory. Formal assessment promotion remains design-ready pending independent reviewers and dry-run.
