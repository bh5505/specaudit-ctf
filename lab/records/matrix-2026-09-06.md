# Head matrix — runner-driven, 4 head instances x 5 graded challenges (2026-09-06)

The first fully runner-driven head matrix: every cell is one
`python -m exercise --head-execute` command (per-cell reports committed
beside this file), spawned by the operator-armed real-head mode
(`exercise/real_head.py`), graded by the unchanged evidence doctrine
(server-side HMAC-chained trace + close record + coverage roster; the
agent's self-report is never the evidence).

- **Provenance**: all sweeps ran the branch at commit `c6622be`
  (identical prompt files, identical incantations; later branch deltas
  touch error paths and tests only). Prompts: `lab/prompts/`
  (identical text per challenge across heads).
- **Hosts**: kali-linux WSL and Ubuntu WSL, each running claude-code
  2.1.261 (LiteLLM tier router) and codex-cli 0.153.4 (abliteration
  provider; replicated to Ubuntu this session from the kali setup).
- **Cell count**: 4 sweeps x 5 graded challenges = 20 cells. Challenge
  `telecom-aws-01-reachability` ships no findings contract (it is the
  envelope-reading tutorial), so the graded head lane does not apply —
  recorded as **not-gradable-by-design**, never fabricated.

## What the numbers do and do not say

- **Tool-call economy**: the claude heads attempt leaner sessions
  (17-30 calls total) than the codex heads (57-64). Because a single
  successful `run_range` covers every fixture, the coverage gate is a
  claim-without-evidence tripwire, not a depth measure — a 2-call pass
  and a 14-call pass grade identically. Call counts are session-shape
  observations, not quality rankings.
- **Duration**: claude cells finish in 6-20s; codex cells take
  39-112s (reasoning-model overhead on the provider). Operator cost
  per matrix sweep is minutes, which is what makes the runner-driven
  form the deliverable.
- **Host symmetry**: both CLIs run identically on both WSL hosts —
  codex@ubuntu (replicated this session) behaves indistinguishably
  from codex@kali.
- **Failure taxonomy (honest record)**: the smoke cell that preceded
  the matrix failed the RIGHT way — a head wrote `found.json` with
  embedded unescaped quotes (baited by an early prompt template) and
  the grader refused the file; the prompt was fixed
  (`tests/test_lab_prompts.py` pins the invariant) and the cell
  re-run. No cell in the committed matrix failed.
